# Release 2.0.0 — October 3, 2026

- Minimal dark layout with an off-white masthead, large lightweight headings, fine dividers, and original subject colors.
- Larger top navigation and responsive phone navigation.
- Removed the search field from Homework; retained filters, sorting, and the global search shortcut.
- Preserved all subject names, teachers, rooms, class periods, timetable entries, clubs, and holiday data from 1.3.5.
- Retained existing browser storage keys and homework fields without automatic migration.
- Improved filters, deadlines, calendar navigation, backup validation, error handling, and recovery.
- Kept demo data isolated from saved homework.

Browser reminders run while the page is open. Back up data using Settings before moving the app to a new address or browser.
